# GitHub Profile Setup Notes

This repository is intended to support a more curated GitHub profile, inspired in part by the way Kalani Craig uses GitHub to surface ongoing scholarly and digital work.

## What GitHub Allows

- You can add a profile README by creating a public repository named exactly `mtebeau`.
- You can pin repositories to your profile; when you do, the pinned section replaces the default "Popular repositories" section.
- Public repositories can be pinned and shown to all visitors.
- Private repositories may be pin-able in some contexts, but they are only visible to viewers who already have permission to access them.

## What That Means For ARCADE

- ARCADE cannot function as a public featured repository if it remains private.
- The best public-facing options are:
  - mention ARCADE prominently in the profile README
  - create a public documentation or overview repository for ARCADE
  - keep the private working repository separate

## Suggested Pinned Repositories

Once this repository and related public repositories exist, a strong pinned set could be:

1. `mtebeau`
   Profile hub and project index
2. `ARCADE-overview`
   Public explanation of the ARCADE project, if you decide to create it
3. `Curatescape`
   Either a documentation repository of your own or a contributed fork/workspace connected to the larger codebase
4. `Pandemic-Archive`
   Public project notes or materials, if appropriate
5. `Arizona-Stories`
   A public-facing documentation repository
6. `Dossier` or `Monuments`
   Depending on which project you want to foreground
